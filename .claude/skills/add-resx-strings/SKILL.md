# Add localized strings

All user-facing text goes through `AppResources`; never hard-code it in XAML or C#. `AppResources.Designer.cs` is only regenerated by Visual Studio, so outside the IDE it is updated by hand together with every `.resx`; a key missing from Designer.cs does not compile, and a key missing from a culture file silently falls back to English.

1. **Pick keys.** PascalCase. Search the neutral `AppResources.resx` first and reuse a key when the text already exists (`Cancel`, `OK`, `Error`, ...). Follow the project's CLAUDE.md if it names conventions.
2. **Write the texts** to a JSON file in your scratchpad:
   ```json
   {"Key": {"": "English text", "ja": "日本語のテキスト"}}
   ```
   `""` is the neutral file; the other names are the cultures of the `AppResources.<culture>.resx` files in the folder. A list `["English", "日本語"]` also works (neutral first, then cultures sorted by name).
   - Placeholders are `{0}`, `{1}`, filled with `string.Format(AppResources.Key, ...)`.
   - Japanese: natural, polite UI wording (です・ます for sentences, short nouns for buttons), full-width 「」 around quoted names.
3. **Run** from the repository root:
   ```bash
   python .claude/skills/add-resx-strings/scripts/add_strings.py <file.json>   # --resources <dir> if there are several resx folders
   ```
   It writes every file at once, keeps each file's BOM and line endings, skips keys that exist, and stops without writing when a culture is missing a text.
4. **Use it:** XAML `Text="{x:Static strings:AppResources.Key}"` with the `xmlns:strings` the project's pages already declare for its `Resources` namespace; C# `AppResources.Key`.
5. **Check:** `git diff --stat` shows only the resx files and Designer.cs you meant to change, then run the project's verification (the build at least; CLAUDE.md names the command, e.g. `tools/verify/verify.sh`). If the text is visible, look at it in every language on a device or emulator.

**Changing an existing string:** edit `<value>` in every `.resx` and the `/// Looks up a localized string similar to ...` line in Designer.cs by hand. **Renaming or removing a key:** change it in all files and grep the code for `AppResources.<Key>` and `x:Static` uses.
